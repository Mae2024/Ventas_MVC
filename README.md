#Ventas_MVC

Aplicación web dedicada a registrar y consultar las ventas diarias de una distribuidora de productos de consumo masivo, como lacteos y fiambres.
Proyecto hecho de práctica con ASP.NET, CORE MVC Y ENTITY FRAMEWORK CORE MAS CLAUDE.

## QUE HACE:

*- Alta, baja y edición de Clientes, productos y ventas
*- Carga de varios productos en un solo cliente
*- Calculo automático del total de la venta
*- Lista de ventas agrupadas por dia o por cliente y con detalle de venta desplegable
*- Filtros por fecha y por cliente
*- bloqueo del borrado de clientes y productos que tengan ventas asociadas

## TECNOLOGIAS USADAS:

*- ASP.NET Core MVC 9.0
*- Entity Framework Core 9.0
*- SQL Server 2022
*- Bootstrap 5.3
*- Entity Framework Core Code First

## COMO SE EJECUTA:

*- Clonar el repositorio
*- Tener instalado Visual Studio 2022 o superior 
*- Abrir el proyecto con Visual Studio
*- Revisar la cadena de conexión en el archivo appsettings.json y cambiarla si es necesario
*- Ejecutar la aplicación con F5 o Ctrl + F5 desde Visual Studio
